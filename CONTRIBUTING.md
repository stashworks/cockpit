# Contributing

Thank you for wanting to help.

**Issues, ideas and bug reports are welcome:** open an issue on GitHub.

**Code contributions (pull requests) are not being accepted at this time.** Cockpit is offered under the AGPL v3.0 and
under a commercial license (see [COMMERCIAL-LICENSE.md](COMMERCIAL-LICENSE.md)). Accepting outside code would first need
an agreement from each contributor that lets the project license their work both ways. When that changes, this file will
say how.
